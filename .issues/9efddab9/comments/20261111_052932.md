Design settled in grill session 2026-11-08; see ADR-0017 (docs/adr/0017-configurable-store-location.md) and plan docs/plans/configurable-store-location.md. Bundle model: --dir (env TODO_TRACKER_DIR) relocates todo.txt+done.txt+.issues/ as a unit; --file (env TODO_FILE) points at the todo index by name or full path (full path implies parent dir for the bundle). Precedence: CLI flags > env vars > defaults. Shared helper todo.apply_store() used by todo.py, todo_webui.py, md2todo.py. md2todo positional 'file' renamed to 'input' (breaking). Missing dirs auto-created; messages use configured file name dynamically.
